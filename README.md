# Goa Hacker ID

Build a visually stunning web app called:

"HACKER HOUSE GOA – ID GENERATOR"

This must exactly match a premium tropical hacker + editorial magazine aesthetic inspired by Goa.

--------------------------------------------------

🎨 CORE THEME:

A fusion of:

- Tropical Goa 🌴

- Hacker culture 💻

- Luxury editorial magazine (like Vogue cover)

--------------------------------------------------

🌈 COLOR SYSTEM (STRICT):

- Deep Green Background: #0B6B3A

- Neon Yellow Text: #FFD600

- Hot Pink Accent: #FF2D7A

- White: #FFFFFF

--------------------------------------------------

🔤 TYPOGRAPHY (VERY IMPORTANT):

1. MAIN HEADING:

- Text: "HACKER HOUSE GOA"

- Font: Playfair Display (or similar high-fashion serif)

- Style: HUGE, bold, uppercase

- Color: Neon Yellow

2. HINDI TEXT (CRITICAL DETAIL):

- Text: "गोवा"

- Style:

   - Fill: Neon Yellow

   - Outline/Stroke: Hot Pink

   - Slight offset/shadow for layered effect

- Position: behind or overlapping "GOA" text like a design element

3. BODY TEXT:

- Font: Inter or Space Grotesk

- Clean, modern

--------------------------------------------------

🌴 BACKGROUND DESIGN:

- Solid deep green base

- Subtle:

  - Palm tree silhouettes (low opacity)

  - Grid / dotted pattern

  - Light grain texture

- Should feel tropical but premium

--------------------------------------------------

🧊 UI STYLE:

- Glassmorphism panels:

  - translucent white/green

  - backdrop blur

  - rounded corners (xl)

- Soft shadows

- Neon highlight accents

- Premium spacing (like Apple / luxury sites)

--------------------------------------------------

🧩 PAGE LAYOUT:

LEFT SIDE:

- Title:

  HACKER HOUSE GOA

  (Hindi "गोवा" layered behind)

- Subtitle:

  "Create your Hacker House Goa ID & PFP Frame"

- Upload Box:

  - Drag & Drop

  - Accept: JPG, PNG, HEIC

  - Rounded dashed border

RIGHT SIDE:

- Live Preview Card

--------------------------------------------------

🪪 ID CARD DESIGN (VERY IMPORTANT):

Card should include:

- Top: "HACKER HOUSE GOA"

- User Photo (square or rounded)

- Name (large, neon yellow)

- Stack / Role (small white text)

- Pink badge:

   - User title (example: "Smart Contract Wizard")

- Bottom:

   #FramedInGoa

Card style:

- Dark green base

- Rounded corners

- Clean layout

- Editorial spacing

--------------------------------------------------

🎲 INPUT FIELDS:

- Name

- Stack / Role

- X Handle

- Title

+ BUTTON:

"ROLL 🎲"

→ generates random hacker-style titles like:

- "DeFi Ninja"

- "Smart Contract Wizard"

- "Protocol Pirate"

- "Zero-Knowledge Monk"

--------------------------------------------------

👤 PFP FRAME MODE:

- Circular avatar

- Thick gradient ring:

   Neon Yellow → Hot Pink

- Dark green background

- Clean minimal style

Toggle between:

[ ID CARD ] and [ PFP FRAME ]

--------------------------------------------------

📤 FEATURES:

- Real-time preview (instant update)

- Download as PNG

- Share button:

   Pre-filled tweet:

   "Just got my Hacker House Goa ID 🔥 #FramedInGoa"

--------------------------------------------------

⚡ ANIMATIONS:

- Smooth fade + slide transitions

- Button hover glow (neon)

- Subtle floating/parallax background

--------------------------------------------------

⚙️ TECH STACK:

- Next.js (App Router)

- Tailwind CSS

- Framer Motion

- html-to-image (for export)

--------------------------------------------------

📱 RESPONSIVE:

- Mobile-first

- Stack layout vertically on small screens

- Keep typography large and bold

--------------------------------------------------

🏆 FINAL GOAL:

The app should:

- Look VIRAL and premium

- Feel like a real event brand

- Be extremely shareable

- Match a Goa hacker + luxury aesthetic perfectly

DO NOT make it generic.

Make it visually striking and unique.

Match spacing, hierarchy, and layout like a high-end landing page.

Use large negative space, strong alignment, and bold typography.

The Hindi "गोवा" must feel like a graphic element, not just text.

Overall vibe = 

"Web3 Hacker Event meets Luxury Fashion Editorial in Goa"
